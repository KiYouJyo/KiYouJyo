## 研究と空間コンピューティング

### 🔬 [UrbanPlanningLab](https://github.com/KiYouJyo/UrbanPlanningLab)

都市・地域計画および国土空間研究のための、長期的かつ再利用・再現可能な研究基盤です。

現在の主な関心：

- 中国と日本の計画制度比較
- 都市域・非都市域における空間ガバナンス
- 都市形態と都市更新
- GIS に基づく空間分析
- 計画コンピュテーションと再現可能な研究

### 🧭 関連プロジェクト

- **[ModernQGIS](https://github.com/KiYouJyo/ModernQGIS)** — QGIS の機能を基盤に、モダンなデスクトップ Shell とインタラクション設計を探る実験プロジェクト。
- **[ReferenceCity](https://github.com/KiYouJyo/ReferenceCity)** — 再現可能な空間実験と手法検証のための標準化された合成都市環境。
- **[SpatialViewer.GisCore](https://github.com/KiYouJyo/SpatialViewer.GisCore)** — Spatial Viewer ファミリーにおける GIS コアの開発。
